# Data sources and licences

The JSON files in this folder are generated by `scripts/refresh_data.py` from the official reference
repositories. See `SOURCES.json` for the exact upstream commits.

| File | Content | Source | Licence |
|---|---|---|---|
| `raweb-1.1-en.json`, `raweb-1.1-fr.json` | RAWeb 1.1 criteria, tests, per-test methodology, WCAG / EN 301 549 references, A/AA level | [accessibility-luxembourg/ReferentielAccessibiliteWeb](https://github.com/accessibility-luxembourg/ReferentielAccessibiliteWeb) (Service information et presse, Luxembourg) | [CC-BY 3.0 LU](https://creativecommons.org/licenses/by/3.0/lu/) |
| `glossary-raweb-en.json`, `glossary-raweb-fr.json` | RAWeb 1.1 glossary | same | CC-BY 3.0 LU |
| `rgaa-4.1.2-fr.json` | RGAA 4.1.2 criteria, tests, per-test methodology, WCAG references | [DISIC/accessibilite.numerique.gouv.fr](https://github.com/DISIC/accessibilite.numerique.gouv.fr) (DINUM, France) | [Licence Ouverte 2.0](https://www.etalab.gouv.fr/licence-ouverte-open-licence/) |
| `glossary-rgaa-fr.json` | RGAA 4.1.2 glossary | same | Licence Ouverte 2.0 |

The A/AA level of each criterion comes from RAWeb's `niveaux.json`; RGAA criteria 1.1 to 13.12 have the
same numbering and the same WCAG mapping, so the same levels apply.

RAWeb 1.1 is an adapted copy of RGAA 4.1.2, itself derived from RGAA 3 (2017) and the AccessiWeb
HTML5/ARIA framework (BrailleNet, 2013). The official, authoritative versions are the published sites:

* RAWeb 1.1: https://accessibilite.public.lu/en/raweb1.1/criteres.html (FR: https://accessibilite.public.lu/fr/raweb1.1/criteres.html)
* RGAA 4.1.2: https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/

When a published version changes, run `python3 scripts/refresh_data.py` to regenerate these files and
the criteria index.

## SIP simplified-audit wording

`sip-report-wording-fr.json` contains the topic recommendations (`topics.json`) and the per-criterion problem/solution
texts (`solutions.json`) of [accessibility-luxembourg/simplA11yGenReport](https://github.com/accessibility-luxembourg/simplA11yGenReport),
the generator the SIP uses for the simplified audit reports it publishes on data.public.lu.
